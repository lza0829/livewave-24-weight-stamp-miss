# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射（关窗冻结热度口径） |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 冻结口径主指标 ↔ 末次撤回 |

## 热度口径（送礼加权热度）

全局单选，任一时刻只有一种口径：

- **金额加权**：主指标 = 点赞增量 + 送礼额 × 权重（默认，权重 2）。
- **等权计数**：主指标 = 点赞增量；送礼额只在窗明细/撤回单旁路展示，不进主指标。

硬规则：

- 关窗即冻结该窗的公式、权重、主指标、口径版本；**改权重/改公式不回写已关窗**。
- 关窗后的迟到修正沿用该窗冻结口径；窗互证按冻结口径重算，不用当前站规重算已关窗。
- 改口径与装载/关窗/贯验共用一把锁：并发交错时改口径 **失败闭（409）**，不排队、不半截提交。
- 站规口径被写坏时只读接口 `valid=false`，装载/关窗 **整批回滚失败闭**。
- 「仅有送礼、无点赞」的窗：等权口径主指标为 0，但窗页给出零因（`等权口径不计送礼（纯送礼窗）`），与空窗（`空窗`）可区分。

只读接口：`GET /api/热度口径`（公式、权重、主指标表达式、valid、口径版本）；变更履历 `GET /api/热度口径/变更`，改口径 `POST /api/热度口径`（可带 `期望版本` 做乐观并发）。

夹具：`纯送礼样例`（同一纯送礼窗——等权主指标 0，金额加权主指标 50×权重）。冒烟：先跑「纯送礼样例」看窗主指标 → 窗参页改权重，已关窗不变 → 再推新事件，新关窗按新权重冻结。

自检：`python3 scripts/口径校验.py`（对临时库跑三组必验夹具：两口径纯送礼窗、改权重不撬已关窗、改公式与关窗并发失败闭）。


## 空桩（邻题扩展）

双钟水位线、允许迟到策略、撤回合并替换、房间级水位线、滑动窗切分、关窗并发半截、水位线回退禁改、旁路升格重放、多房串扰隔离、空窗发射策略、撤回幂等键、处理时乱序缓冲、窗键对齐互证、热度上限截断、开播闭播切流。
