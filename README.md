# 播浪

中文名：**播浪** · 前缀 `livewave` · 端口 **6400 / 11400**

## 骨架

**互动事件入流 → 事件时间水位线推进 → 热度窗关闭发射 → 迟到修正/撤回 → 窗输出与撤回互证**

皮：直播间点赞/送礼互动。去皮是事件时间窗计算 + 允许迟到与撤回，不是直播运营后台 CRUD，不是点击会话空闲切开。

## 冒烟

```bash
docker compose up -d --build
# http://127.0.0.1:6400
# 入流 → 灌「准时热度样例」→ 水位线/热度窗 → 再灌「迟到修正样例」看撤回 → 贯验
```

## 主链对象

| 对象 | 作用 |
| --- | --- |
| 互动事件 | 带事件时/处理时的点赞送礼 |
| 水位线 | 每房事件时水位 + 允许迟到秒 |
| 热度窗 | 翻滚窗；开启累计，关闭发射（关窗冻结热度口径） |
| 撤回单 | 已关闭窗被允许迟到事件修正 |
| 旁路匣 | 超允许迟到 |
| 权重世代戳 | 加权入窗成功即钉死当时世代（主指标/权重/公式版本/戳号） |
| 窗贯验 | 窗合计 ↔ 事件合计 ↔ 逐笔世代主指标 ↔ 末次撤回 ↔ 戳核证 |

## 热度口径（送礼加权热度）

全局单选，任一时刻只有一种口径：

- **金额加权**：主指标 = 点赞增量 + 送礼额 × 权重（默认，权重 2）。
- **等权计数**：主指标 = 点赞增量；送礼额只在窗明细/撤回单旁路展示，不进主指标。

硬规则：

- 关窗即冻结该窗的公式、权重、主指标、口径版本；**改权重/改公式不回写已关窗**。
- 关窗后的迟到修正沿用该窗冻结口径；窗互证按逐笔世代重算，不用当前站规重算已关窗。
- 改口径与装载/关窗/贯验共用一把锁：并发交错时改口径 **失败闭（409）**，不排队、不半截提交。
- 站规口径被写坏时只读接口 `valid=false`，装载/关窗 **整批回滚失败闭**。
- 「仅有送礼、无点赞」的窗：等权口径主指标为 0，但窗页给出零因（`等权口径不计送礼（纯送礼窗）`），与空窗（`空窗`）可区分。

### 权重世代戳（入窗戳冻结发射）

设计取舍全局只贯彻一种：**入窗戳冻结发射**——发射主指标必须等于戳内累计，现行权重不得回溯。

- 加权入窗成功时，同一事务、同一票写入权重世代戳：窗键、权重值、公式版本、累计主指标、戳号、时刻。**禁止加权入窗成功戳空**。
- 每笔按**当时**站规世代累进增量主指标；新累计 = 窗行主指标 + 本笔增量。**禁止发射用另一套权重重算已累计**。
- 关窗发射把窗行主指标/公式/权重/口径版本四件套全部取自同一枚最新戳；**禁止戳内主指标与窗行分叉还关闭**（分叉失败闭、窗保持开启）。
- 迟到修正沿用该窗冻结世代：写新戳 + 撤回单 + 更新窗行，整票提交；戳缺失时失败闭。
- 改权重与关窗抢锁：装载持 `口径.锁`，改口径拿不到锁即失败闭（409），不会出现半截混用公式版本。
- 戳写失败一律上抛，装载整票回滚，绝不出现「累计已加、戳空」。

只读接口：`GET /api/核证/权重世代[?窗键=]`（权重戳明细、钉死、缺戳窗、窗行与戳一致性、设计取舍）。它与累计写闸、发射写闸、迟到写、热度台/热度窗页共用同一套戳语义。

只读接口：`GET /api/热度口径`（公式、权重、主指标表达式、valid、口径版本）；变更履历 `GET /api/热度口径/变更`，改口径 `POST /api/热度口径`（可带 `期望版本` 做乐观并发）。

夹具：`纯送礼样例`（同一纯送礼窗——等权主指标 0，金额加权主指标 50×权重）。冒烟：先跑「纯送礼样例」看窗主指标 → 窗参页改权重，已关窗不变 → 再推新事件，已累计窗按戳内世代，新窗按新权重冻结；`权重世代核证` 页核对每窗戳内累计 = 窗行主指标。

自检：`python3 scripts/口径校验.py`（对临时库跑八组必验：两口径纯送礼窗、改权重不撬已关窗、改公式与关窗并发失败闭；甲 改权重后再发射锁在戳内值、乙 缺戳失败闭整票回滚、戳分叉拒关、改权重与关窗抢锁不半截、只读核证与写闸协同）。


## 空桩（邻题扩展）
